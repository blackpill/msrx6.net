Bluetooth support is limited to **MSRX6BT or Bluetooth-labeled hardware**. A USB-only MSRX6 cannot gain Bluetooth through an app or driver.

## Android

1. Install the compatible app from [Google Play](https://play.google.com/store/apps/details?id=com.easymsr&referrer=utm_source%3Dmsrx6.net%26utm_medium%3Dorganic).
2. Enable Bluetooth and grant only the permissions required for device discovery.
3. Power the MSRX6BT and select it inside the app if the app provides its own scanner.
4. Test the connection using non-sensitive test media.

## iOS {#ios}

1. Install the compatible app from the [Apple App Store](https://apps.apple.com/app/apple-store/id6483249260?pt=126665557&ct=msrx6.net&mt=8).
2. Allow Bluetooth access when prompted.
3. Follow the app's device-discovery flow. Some accessories pair inside the app rather than in iOS Settings.

## Pairing problems

- Charge or power the device and keep it close to the phone.
- Disconnect it from any computer or phone already using it.
- Restart Bluetooth, then retry from the app.
- Verify that the hardware label includes Bluetooth/MSRX6BT.
- Do not repeatedly guess PINs; consult the supplied documentation or vendor.
