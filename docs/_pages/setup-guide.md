## 1. Confirm hardware and platform

Check whether the label says MSRX6 or MSRX6BT. Choose [Windows](/windows-driver/), [Mac](/mac-software/), [Android](/android-app/), or [Bluetooth/iOS](/bluetooth-software/) guidance.

## 2. Prepare a safe test environment

Use blank test media or cards belonging to an authorized test system. Never test with a live payment card, government ID, hotel key, or access credential without explicit authorization.

## 3. Install and connect

Scan the download, install it, and connect the device directly. Verify that the operating system recognizes the hardware before opening the application.

## 4. Validate operation

Start with a read-only test on non-sensitive media if supported. Confirm the expected device and track settings before any authorized write operation. Keep an audit trail in organizational environments.

## 5. Finish securely

Close the application, remove test data, disconnect the device, and store both hardware and output files securely.

For errors, continue to [Troubleshooting](/troubleshooting/).
