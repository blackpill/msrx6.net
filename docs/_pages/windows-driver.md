The desktop package supports common MSRX6, MSRX6BT, and MSR605X workflows on Windows. Hardware revisions differ, so verify the model label first.

[Download the Windows ZIP](https://fileus.tinylock.cn/msr/x6x6bt605x/windows.zip)

## Install on Windows 10 or 11

1. Download and scan the ZIP archive.
2. Extract it to a local folder; do not run the installer from inside the ZIP.
3. Right-click the installer and review its publisher and properties.
4. Install with the MSR X6 disconnected unless the installer says otherwise.
5. Connect the device directly to the computer, avoiding an unpowered USB hub.
6. Confirm that Windows detects the device, then open the software.
7. Test only with blank or authorized test media.

## If Windows does not detect MSR X6

- Try a known data-capable USB cable and another USB port.
- Open Device Manager and check for an unknown USB or serial device.
- Remove an incomplete driver installation, restart, and reinstall once.
- Avoid compatibility mode unless the current installer fails normally.

See [MSR X6 troubleshooting](/troubleshooting/) for detailed checks.
