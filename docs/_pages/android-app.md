The Android app works with supported **Bluetooth/MSRX6BT** hardware, not USB-only models.

[Open the app on Google Play](https://play.google.com/store/apps/details?id=com.easymsr&referrer=utm_source%3Dmsrx6.net%26utm_medium%3Dorganic)

## Safe setup

1. Confirm the app publisher, update date, reviews, and permissions on Google Play.
2. Install from Google Play rather than an unknown APK mirror.
3. Grant nearby-device/Bluetooth access only when required.
4. Pair from inside the app if instructed.
5. Do not import or retain real payment-card data on a personal phone.

For connection steps, see [Bluetooth software and setup](/bluetooth-software/).
